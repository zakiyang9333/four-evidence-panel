# 四要素观察面板

本地网页 App，用来观察“抄底核心四要素”规则在 SPCX、NVDA、QQQ 上的状态。只看收盘后的日线，不接券商，不下单。

**四证：回测证据不足 ｜ 后手战法、破位反抽：尚未回测 ｜ 仅观察，不构成买卖依据**

## 启动

**平时不用管它。** 运行过一次 `start_with_key.sh`（见下面“接入 Claude API”）之后：

- 面板登录后自动启动，挂了 30 秒内自动拉起；密钥从 macOS 钥匙串取，不用再复制。
- 周二到周六台北时间 06:30、08:30、10:30 自动刷新日线（美股收盘后），只追加新日期。
- 打开方式：浏览器 <http://localhost:8777>，或双击 `四要素面板.app` / 运行 `./open_window.sh` 打开独立窗口。

| 要做的事 | 命令 |
|---|---|
| 接 API / 换密钥（先复制密钥） | `./start_with_key.sh` |
| 暂时停掉面板（下次登录还会自动启动） | `./stop.sh` |
| 取消自动启动和定时刷新 | `scripts/uninstall_agents.sh`（加 `--forget-key` 同时删掉钥匙串里的密钥） |
| 不用自动启动，临时在前台跑 | `./start.sh`（Ctrl+C 停止，这样跑不会带密钥） |

日志在 `logs/`：`panel.log`（只有请求行）、`refresh.log`、`window.log`。没有密钥，也没有持仓数字。

第一次启动会在本目录建 `.venv` 并安装依赖（numpy、anthropic），需要联网，之后启动不再安装。定时任务沿用你终端里的代理设置（安装时从当前环境抄过去）；代理地址换了，重新运行一次 `start_with_key.sh` 或 `scripts/install_agents.sh`。

端口是 8777，不是任务说明里写的 8765：这台 Mac 上 8765 被数据看板占用，8766 也有进程在用，面板不会去动它们。要换端口，改 `config.json` 的 `port`，或者临时 `FE_PORT=8778 ./start.sh`。

- **AI 解读有记忆**（存在本机 `cache/ai/`，不进 git；每只标的每天留最近 5 版）：
  - 打开面板、切回分析过的标的和日期，直接显示保存的那一版，不用点、不调用 API。“重播”也不计费。
  - 判断“还是不是同一份”只看盘面和仓位：引擎事实、最近 60 根 K 线、回测摘要、这只标的相关的仓位。换模型、改提示词、仓位文件重新同步但内容没变、日子往后过了几天，都不算变，不会让你重新花钱。
  - 盘面没变时点“重新分析”要点两次：第一下按钮变黄问一句，5 秒内再点才真的调用。后端也守着：不带 `force` 的请求碰到同一盘面，直接给回保存的那一版。
  - 数据或仓位确实变过，保存的那一版仍会显示，标“之后数据或仓位变过”，按钮是“按新数据重新分析（会计费）”。
  - 每次调用用了多少 token 写在解说标题旁边。

## 接入 Claude API（AI 解读）

不接也能用，只是侧栏里“AI 分析当前图表”那个按钮是灰的。接入步骤：

**最省事的办法：一条命令**

在控制台的 API Keys 页面点“复制”，把密钥放进剪贴板，然后运行：

```bash
~/Applications/VIXWatch/four_evidence/start_with_key.sh
```

它从剪贴板读密钥（不显示、不写进文件，读完清空剪贴板），直接问一次 Claude API 这个密钥认不认（不花钱），把密钥存进 macOS 钥匙串（服务名 `four-evidence-anthropic-key`），装好自动启动和定时刷新，再用新密钥重启面板。之后重启电脑也不用再复制。换密钥时再做一遍就行。

在“钥匙串访问”App 里搜 `four-evidence` 能看到这条密钥；要删掉它，运行 `scripts/uninstall_agents.sh --forget-key`。

下面是手动的做法，效果一样。

**1. 拿到 API 密钥**

登录 <https://platform.claude.com>（Anthropic 的开发者控制台），在 API Keys 页面新建一个密钥，形如 `sk-ant-...`。密钥只在创建时显示一次，先复制好。账户里需要有可用额度。

**2. 把密钥放进环境变量**

面板只从环境变量 `ANTHROPIC_API_KEY` 读密钥。不要把它写进 `config.json`、代码或聊天记录。

只对当前这个终端窗口生效（关掉窗口就没了）：

```bash
export ANTHROPIC_API_KEY='把你的密钥粘贴在这对引号里'
```

想以后每次开终端都有，把上面这一行加到 `~/.zshrc` 的末尾，然后开一个新终端窗口。

**3. 在同一个终端里启动面板**

```bash
./start.sh
```

启动信息里看到 `AI 解读：可用，模型 claude-fable-5-2` 就说明密钥读到了。如果看到“不可用”，说明这个终端里没有这个环境变量，回到第 2 步。

**4. 使用**

打开页面，点右上角“AI 量化”展开侧栏，再点“AI 分析当前图表”。等十几秒到一两分钟，下面会出现一段中文解读。回放到历史某天再点，解读的就是那一天的状态。

**5. 停用**

```bash
unset ANTHROPIC_API_KEY
```

再重启面板，按钮回到灰色，其他功能不变。

### 它会把什么发给 Claude

每点一次按钮，后端发一次请求，内容只有三样：

1. 规则引擎在当前（或回放）那天算出的状态：结论、四项证据各自是否成立和原因、高点、低点、扇子中线、成本线、止损、目标；
2. 截至那天的最近 60 根日 K 线；
3. 回测摘要（26 笔，平均 0.435R，对照组 0.165R，p = 0.17）。

提示词写死了边界：结论以规则模型为准，它只解释原因和风险，不给买卖指令。它改不了证据条和侧栏上半部分的任何数字。

### 换模型和其他设置

改 `config.json`，然后重启面板：

| 键 | 默认 | 含义 |
|---|---|---|
| `ai_model` | `claude-fable-5-2` | 模型名（11-14 按 zaki 的要求从 `claude-opus-5-5` 换成 Fable 5.2）。想省钱可以换 `claude-opus-5-5`、`claude-sonnet-5-5` 或 `claude-haiku-5-5` |
| `ai_effort` | `medium` | 思考深度：`low` / `medium` / `high`。越高越慢越贵 |
| `ai_max_tokens` | 16000 | 单次回复的长度上限（含思考） |
| `ai_timeout_s` | 300 | 单次请求最长等多少秒 |
| `portfolio_poll_s` | 15 | 页面每隔多少秒问一次持仓文件有没有变（5–60） |
| `ai_refusal_fallback` | `true` | 模型拒绝回答时，由 API 自动换默认的备用模型再答一次 |

也可以临时换模型：`FE_AI_MODEL=claude-sonnet-5-5 ./start.sh`。

费用按用量计。每次请求的输入大约三四千 token，输出几百到几千 token（含思考），Fable 5.2 的单价是每百万 token 输入 8 美元、输出 40 美元，大约是 Opus 5.5 的两倍，估算每次几美分到一两毛。这是估算，没有实测过。Fable 5.2 思考更久，单次可能要等一两分钟。

### 常见问题

| 页面上的提示 | 原因和处理 |
|---|---|
| 没有设置环境变量 ANTHROPIC_API_KEY | 启动面板的那个终端里没有这个变量。在同一个终端里 `export` 后再 `./start.sh` |
| API 密钥无效或已失效（401） | 密钥贴错或被删。重新建一个 |
| 这个密钥没有权限使用模型（403）/ 找不到模型（404） | 换 `ai_model`，或在控制台确认账户能用这个模型 |
| 请求太频繁或额度用完（429） | 等一会儿，或在控制台查额度 |
| 连不上 Claude API | 网络到不了 `api.anthropic.com`。如果你平时要走代理，在启动前 `export HTTPS_PROXY=http://127.0.0.1:端口`（换成你代理的地址）；走网关的话设 `ANTHROPIC_BASE_URL` |

### 目前验证到哪一步

2026-11-14 用 zaki 的密钥对真实的 Claude API 跑通了一次：QQQ，模型 `claude-fable-5-2`，14 秒返回，解读复述了规则模型的结论，没有给买卖指令。这只标的没有相关仓位，所以**带仓位的那种请求（SPCX、NVDA）还没有对真实 API 跑过**，只对本机的假 Claude 服务验证过请求内容。

另外已验证：没有密钥时按钮置灰、其余功能正常；密钥不出现在日志和前端。

`start_with_key.sh` 里的密钥检查只是参考：它查的是模型列表，`sk-ant-usr` 类型的密钥在这一步会得到 403，但实际的解读请求是能用的。

## AI 解说（视频式四问）和盘中实时

**AI 解说**（11-16 按 APP_ADDENDUM_AI.md 改）：点侧栏的“AI 分析”，先出**模板版**（不调用 API，不花钱）：一句定性，然后四问依次出现（量 → MACD → 扇子 → 成本线），每问一句大字判断、一行事实、一个黄色贴纸，证据条跟着一条一条亮，最后是大字结论和“下一根 K 线看什么”。点哪一问，图上对应的位置闪一下。

- “让 Claude 润色（会计费）”是**自由分析**（zaki 11-16 改：市场变化多，内容不要固定框架，只保留模板版那种呈现方式）。Claude 自己决定讲什么、讲 2–8 步、什么顺序：量价、形态、缺口、压力支撑、仓位离关键价位的距离等都可以，四要素只是其中一个角度。版式不变：一句定性、一张张卡片（小标题、一句大字判断、一行事实、贴纸）、大字结论、接下来盯什么。
- **文字短，证据画在图上**（zaki 11-16：成段的日期和价格“过于啰嗦，干扰思考”，要动画和可视化）。Claude 版的卡片只有小标题、一句不超过 18 字的判断和贴纸，不再有罗列数字的小字。每一步另外带一组“画图指令”：圈出某几根 K 线、把几个高点或低点连成线、画一条价位线、涂出一段震荡区、指出某几天的量或 MACD。卡片出现时，图上同步一笔一笔画出来，并自动拉近到相关的那一段；播放结束或再点一次，视野恢复。
- 画图指令里 Claude 只说“哪一天、最高还是最低”，价位由后端从真实 K 线里取，所以图上标的价格不可能是编的。指向不存在的交易日、回放日之后的日子、或输入里没有的价位，这条标记会被丢掉。
- 之前保存的老格式解说（有成段文字的）仍能看：文字收进悬停提示，点卡片时从文字里读出日期和价位标在图上。
- 引擎说了算的只剩两处：某张卡片标明讲的是四要素第几项时，成立与否取引擎的结果，贴纸和引擎矛盾就换掉；大字结论不能和引擎的入场结论相反。提示词里另外要求不给下单指令。
- 数字核对：解说里的每个数字都和输入比对，认可的范围是输入里的原值、四舍五入、百分比换算、成交量换成万 / 百万 / 亿、两个价位的差和涨跌幅。对不上的**标黄提醒**，不丢弃整段。想恢复“有一个对不上就整段改用模板”，在 `config.json` 加 `"ai_strict_numbers": true`。中文数字（“三成”）不在核对范围内。
- 没有密钥、断网、Claude 返回的不是合法 JSON（重试一次后）时，同样退回模板版并说明原因。
- “规则模型信号”卡片（结论、三行大字、入场区间、止损、目标、盈亏比）全部由引擎填，不经过 Claude。入场区间按 `four_evidence_check.py` 的定义（成本线到 +2%），只在 4/4 时给。
- 测试开关：地址加 `?aifake=1` 后点润色，后端会往 Claude 的输出里塞一个假数字，用来确认核对能拦住。`?narr=1` 打开页面就播放解说。

**盘中实时**（“指标”菜单里可关）：今天常规交易时段的未收盘 K 线，用半透明画在最后一根已入库 K 线的右边，成交量柱也是半透明；图例里写明“未收盘，不参与判定”。

- 来源是 Yahoo 的实时推送（和 yfinance 用的同一个）加每分钟一次的 1 分钟线校正，不需要注册账户。盘中每 3 秒更新一次页面。
- 只有常规时段（美东 9:30–16:00）的成交价进这根 K 线；盘前、盘后、夜盘的价格只在图例里显示为场外价。
- 这根 K 线不写进 `data/*.csv`、不交给引擎，证据条、侧栏、AI 解说都不看它。当天的日线由定时任务入库后，它自动消失。回放时不显示。
- 没人看页面 10 分钟后，后端断开推送。休市时想看效果：地址加 `?livedemo=1`（模拟数据）。

## 「持仓」页

顶栏点“持仓”进入，点“图表”或任何一只标的回到 K 线。全部只读：面板从不写、不改、不删 `portfolio/` 里的文件。

- **数据来源**：`portfolio/portfolio_state.json`（云端持仓分析线程写入）和 `portfolio/*_app.md`（App 快照原文）。
- **自动更新**：页面每 15 秒问一次后端，后端看文件的修改时间，变了就重新读取，不用手动刷新。页顶显示“持仓更新于 …”（文件的修改时间）和“数据时间”（文件里的 `asof_taipei`）。
- **过期提示**：数据时间超过 24 小时，页顶标黄“持仓数据已过期，以券商 App 为准”，顶栏的持仓标签也会标“已过期”。数据时间读不出来也按过期处理。
- **没有文件**：持仓页显示“没有持仓数据”，图表页不受影响。文件只写了一半（不是完整 JSON）时也不显示数据，等下一次同步。
- **页面内容**：账户卡片、杠铃分布（堆叠条按净值的百分比画，虚线标出 1 倍净值）、持仓表、其它账户、关键价位、逆向检查清单（命中的标红）、快照原文（下拉框切换历史快照）。

## 时效与备注：那一天发生过什么（2026-11-16）

AI 分析只看价格和成交量，说不出跳空或天量的原因。这一层把“当时发生过什么”挂到 K 线上，并写明每样信息有多新。

**图上**：主图底部，有备注的 K 线下面有一个小方块。财 = 财报日，息 = 除息，拆 = 拆股，闻 = 新闻标题，搜 = 联网搜到的，记 = 你写的。鼠标移上去看内容，点一下看全部（带原文链接）。右下角写着下一次财报还有几天。图上右键某根 K 线：写备注，或让 Claude 联网查这一天。

**侧栏「时效与备注」卡片**：K 线数据截到哪天；AI 解读是哪天生成的、之后又新增了几条它没看到的备注；事件日历什么时候更新的（超过 7 天标“可能过时”）；新闻存档从哪天开始；下次财报；最近 60 根里动静最大的 5 天各有没有备注。

**四种来源**（`notes.py`，存在本机 `data/notes/`，不进 git）：

| 来源 | 有没有历史 | 说明 |
|---|---|---|
| 事件日（财报、除息、拆股） | 有 | Yahoo Finance。算事实。每次刷新数据时更新。 |
| 新闻标题 | 只有开始存档之后的 | Yahoo 只给最近十来条，所以每次刷新存一批（标题、媒体名、链接，不存正文）。过去的补不回来。英文标题会自动翻成中文存下来（每条只翻一次，一批十条约 800 入 + 400 出 token；`config.json` 里 `ai_translate_auto` 设成 false 可关，`ai_translate_model` 可换便宜的模型），原文留在点开的弹窗里。最后一根 K 线之后的消息先列在时效卡片里。 |
| Claude 联网搜 | 想查哪天查哪天 | 花钱。每条必须带着搜索结果里真实出现过的链接，对不上的丢掉；查过的日子记下来，不再查第二遍。原始返回留在 `cache/ai/search/`。 |
| 手写备注 | 你写了就有 | 只在本机。 |

**规矩**：

- 备注不进规则引擎，不改任何证据的判定（有测试）。
- 回放到某一天，只给那一天以及之前的备注；“下一次财报”只在看最新一根时显示。
- AI 解说的卡片上只带三种备注：事件日、你手写的、联网搜到并核对过的中文概括；每条一行，同一条只出现一次，每张卡片最多两条。原始新闻标题不上卡片（又长又杂，多半是英文的大盘消息），要看就在图底部的小方块上悬停或点开。
- 交给 Claude 的只有日期、类别、一句内容和来源。提示词要求它：讲到的 K 线有备注就带上，没有备注就说不知道那天发生了什么，不许猜。
- 新增备注不会让保存过的 AI 解读作废（不会让你再花钱），只在时效卡片里提示“之后新增了几条，它没看到”。
- 联网搜用的是基础版搜索工具 `web_search_20250305`。带“动态筛选”的新版在实测里把自己的筛选代码跑崩、交了空列表，所以没用；要换回去改 `config.json` 的 `ai_search_tool`。

**在 GitHub 上看过的其它方案**（没用上，原因写在这里）：GDELT 的免费新闻检索接口（`alex9smith/gdelt-doc-api`）在这台机器上连试三次都被限流；Finnhub（`Finnhub-Stock-API/finnhub-python`）要注册密钥；SEC 公告（`dgunning/edgartools`）要在请求里留联系邮箱。宏观日历（议息、CPI）没有找到可靠的现成来源，暂时没做。

定时刷新（`scripts/run_refresh.sh`）会顺带跑 `notes.py --refresh`。测试：`.venv/bin/python tests/test_notes.py`。
